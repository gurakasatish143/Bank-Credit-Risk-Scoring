# Bank-Credit-Risk-Scoring

A client project focused on analyzing bank customer data and assessing credit risk using data analysis and machine learning.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Activities

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Credit risk analysis
- Machine learning model development and evaluation

## Project Objective

To analyze customer information and develop a model to help assess credit risk.

## Project Type

Data Analytics / Machine Learning
